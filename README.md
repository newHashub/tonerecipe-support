# ToneRecipe for iPhone · 调色参数识别与预设

ToneRecipe 可以把博主分享的调色文字或参数截图，变成能检查、应用和保存的照片配方。复制参数文字后粘贴识别，或导入参数截图，核对数值后应用到自己的照片，再微调并保存为预设。

- [中文产品介绍与操作教程](https://newhashub.github.io/tonerecipe-support/zh-cn/apps/tonerecipe/)
- [复制文字参数，不用逐个调整滑杆](https://newhashub.github.io/tonerecipe-support/zh-cn/apps/tonerecipe/#text-recipe)
- [中国大陆 App Store](https://apps.apple.com/cn/app/tonerecipe/id6799357040)

ToneRecipe reads photo editing settings from text or a screenshot. Review the recognized values, apply them to your photo, fine-tune the result, and save a reusable preset.

- [English product guide](https://newhashub.github.io/tonerecipe-support/en/apps/tonerecipe/)
- [Paste a creator’s settings without adjusting every slider](https://newhashub.github.io/tonerecipe-support/en/apps/tonerecipe/#text-recipe)
- [U.S. App Store](https://apps.apple.com/us/app/tonerecipe/id6799357040)

Requires iOS 17 or later; supports English and Simplified Chinese. Available in China mainland, the United States, the United Kingdom, Canada, Australia, New Zealand, and Singapore. [All download regions](https://newhashub.github.io/tonerecipe-support/#download).

Recognition and editing run on device. Reference-photo matching estimates a starting recipe; it does not recover the creator’s original settings. Results can vary by photo and editor. Recognition, editing, and presets are free to use, with five successful image exports per calendar month. A one-time Pro purchase unlocks unlimited exports.

## Search-engine maintenance

The homepage retains Google and Bing site-verification tags. The public hexadecimal `.txt` file proves ownership of this website path for IndexNow; it is not an account credential.

After publishing a changed page, run `python3 tools/notify-indexnow.py <canonical-url>` to inspect the notification, then add `--submit` to send it. Omit URLs only for the initial submission of all sitemap pages. The helper checks the deployed ownership file and pages before sending. It uses Python's standard library and adds no dependencies. Do not repeatedly submit unchanged pages.

The default endpoint shares notifications with participating IndexNow search engines. HTTP 200 means received; HTTP 202 means ownership validation is pending. Neither response confirms indexing. Google Search Console requests and actual index inspection are separate.
