# ToneRecipe Support Site

Static, dependency-free privacy and support pages for ToneRecipe.

- Public root: `https://newhashub.github.io/tonerecipe-support/`
- Privacy: `https://newhashub.github.io/tonerecipe-support/privacy/`
- Support: `https://newhashub.github.io/tonerecipe-support/support/`

The public repository contains only this directory's static files. It does not
contain the ToneRecipe application source code. The pages intentionally use no
JavaScript, cookies, analytics, remote fonts, or third-party assets.
